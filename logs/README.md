# logs/

**Part 3 — The paper trail (sessions).**

One file per session. Humans and agents both write these. The overnight hook does not invent work that did not happen.

## Name

`YYYY-MM-DD-<slug>.md` — slug is 2–5 words, kebab-case.

Copy [`_template.md`](./_template.md). Then append one bullet to [`ACTIVITY.md`](../ACTIVITY.md).

## What to include

- Goal in one sentence
- What changed (paths)
- Facts promoted or graveyarded
- Decisions proposed or accepted
- Open loops for the next session

Not a transcript dump. If the transcript matters, put a redacted copy in `calls/` and link it.
