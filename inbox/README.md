# inbox/

**Part 1 — Somewhere to drop things.**

Notes, screenshots, half-formed ideas. Filing is a later session. Capture is this one.

## Drop a thing

1. Copy [`_template.md`](./_template.md) to `inbox/YYYY-MM-DD-<slug>.md` (or drop an image next to a short `.md` that names it).
2. Fill **what it is** and **why it might matter**. Guessing is allowed.
3. Stop. Do not promote in the same breath unless it is already a proven fact.

Screenshots: `inbox/YYYY-MM-DD-<slug>.png` (or webp) + a sidecar `.md` with alt text and source.

## What does *not* belong here

| That is… | Put it in… |
|----------|------------|
| A fact we will work from | `knowledge/` + INDEX |
| A transcript | `calls/` |
| A decision | `DECISIONS.md` |
| A personal draft you will keep editing | `workspaces/<handle>/` |
| A secret | nowhere in git |

## Overnight

`hooks/daily.md` nags on inbox items older than 7 days. Promote, graveyard, or delete *noise* (noise only — never a disproven fact; those go to `_graveyard.md`).
