# skills/

**Part 5 — How the agent behaves** (repeatable tasks).

Each skill is a folder with `SKILL.md`. Load a skill when the job matches; do not paste all skills into every session.

| Skill | When |
|-------|------|
| [promote-inbox](./promote-inbox/SKILL.md) | An inbox note is ready to become knowledge (or noise) |
| [ingest-call](./ingest-call/SKILL.md) | A transcript landed in `calls/` |
| [record-decision](./record-decision/SKILL.md) | We made a choice that future-us will argue with |
| [close-session](./close-session/SKILL.md) | End of every session — non-optional |
| [file-knowledge](./file-knowledge/SKILL.md) | A confirmed fact needs a topic file + INDEX |

Operating manual: [`CLAUDE.md`](../CLAUDE.md). Overnight: [`hooks/daily.md`](../hooks/daily.md).
