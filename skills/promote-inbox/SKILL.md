# Skill: promote-inbox

## When to use

An `inbox/` note (or screenshot sidecar) is older than a day, or the human says “file this.”

## Do

1. Read the inbox file and `knowledge/INDEX.md`.
2. Choose one:
   - **Noise** — delete the inbox file (not a false fact).
   - **Unsure** — add a row to `knowledge/_provisional.md` with ID `P-xxx`, owner, kill-by. Remove or stub the inbox file.
   - **Fact** — follow `skills/file-knowledge`. Then delete the inbox file.
   - **Decision** — follow `skills/record-decision`. Then delete the inbox file.
3. Append `ACTIVITY.md`.
4. Do not rewrite the note into a blog post in `knowledge/`.

## Don’t

- Promote guesses as topic facts.
- Leave a duplicate in inbox *and* knowledge.
